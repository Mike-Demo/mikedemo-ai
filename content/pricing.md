# Pricing

mikedemo.dev is a personal portfolio site. Everything on it is free.

## Tiers

There is one tier: **free**.

- Browsing projects, reading the skills directory, and fetching the machine-readable files (`/api/v1/*.json`, `/openapi.json`, `/llms.txt`) cost nothing.
- No accounts, no API keys, no paid plans, no usage limits.

## The projects themselves

Each portfolio project links out to its own live site or repository. Those destinations have their own terms; mikedemo.dev itself charges nothing and sells nothing.
