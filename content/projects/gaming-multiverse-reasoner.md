# Gaming Multiverse Reasoner

Every game is connected: find the hidden paths, bridge nodes, and communities between any two to four games.

## About

Gaming Multiverse Reasoner builds a graph of more than 50,000 games (84,000+ nodes, over a million edges) in FalkorDB and computes the hidden paths, bridge nodes, and communities joining any set of games, narrated live by IBM watsonx on IBM Cloud Code Engine. Built for the WeMakeDevs x FalkorDB Graph Hacks hackathon.
