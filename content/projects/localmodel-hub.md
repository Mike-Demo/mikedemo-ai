# LocalModel Hub

A privacy-first AI assistant that runs open-source LLMs entirely in your browser — your data never leaves your machine.

## About

LocalModel Hub (privatebrain.app) is a privacy-first, open-source model discovery and chat app that runs open-source large language models entirely on-device in the browser. No server inference, no account, nothing sent anywhere after the model file is fetched. Built for Bolt Builder Week.
