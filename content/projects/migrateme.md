# MigrateMe

An open-source, dry-run-first toolkit for migrating CMS content — WordPress to Markdown/MDX first, anything-to-anything next.

## About

MigrateMe is an open-source AI-assisted CMS migration toolkit: dry-run-first and local-first, it migrates WordPress content to Markdown/MDX via CLI, MCP, web, and agents. Its Universal edition routes every source through a canonical manifest (the Open Migration Package) so any source can go to any destination without N×N converters.
