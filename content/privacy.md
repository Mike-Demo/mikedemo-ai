# Privacy policy

Last updated: October 3, 2026.

## The short version

mikedemo.dev is a fully static portfolio. There are no accounts, no login, no comments, no newsletter signup, and no contact form — so the site itself collects nothing about you, sets no tracking cookies, and stores no personal data.

## Analytics

The site loads a lightweight, cookieless analytics tracker (umami-lite) that counts page views without cookies and without storing IP addresses. No cross-site tracking, no advertising profiles.

## Third parties

Fonts, icons, and stylesheets load from the jsDelivr CDN; pages are served by SpaceFast static hosting. Those providers see the same technical request data any web host sees (IP address, user agent) when your browser fetches files from them. Projects linked from this portfolio are separate sites with their own policies.

## AI crawlers

AI crawlers and agent user-agents are explicitly welcome (see [/robots.txt](https://mikedemo.dev/robots.txt)). The machine-readable files on this site — llms.txt, the JSON API, the ARD catalog — exist so agents can read the portfolio without scraping HTML.

## Questions

Privacy questions: reach out via any public profile on the [contact page](https://mikedemo.dev/contact/).
