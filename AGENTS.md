# AGENTS.md — mikedemo-ai

Instructions for AI coding agents working on this repository (the source for https://mikedemo.dev, Mike "Demo" Demopoulos's AI project portfolio).

## What this is

A TanStack Start (React) site that prerenders to **fully static HTML** at build time. There is no server at runtime: no login, no request-time data fetching, no webhooks. It deploys to SpaceFast static hosting, which builds `main` automatically.

## Build

```
node scripts/generate-projects.mjs   # Supabase -> src/data/projects.generated.ts (needs SUPABASE_URL / SUPABASE_PUBLISHABLE_KEY)
node scripts/generate-api-json.mjs   # generated TS -> public/api/v1/*.json (committed)
node scripts/generate-sitemap.mjs
vite build
node scripts/copy-static-output.mjs
node scripts/generate-md-txt.mjs     # content/*.md -> dist/client/md/*.txt (markdown twins)
```

`npm run build` runs all of the above. See SPACEFAST.md for the two build targets (static vs Lovable/Cloudflare) and the hard rules: never commit `wrangler.*`, keep the `@cloudflare/vite-plugin` import lazy.

## Conventions

- Project data is generated — never hand-edit `src/data/projects.generated.ts`; change the database or the generator.
- `public/api/v1/*.json` are committed build artifacts regenerated by `generate-api-json.mjs`; don't hand-edit them either.
- Markdown sources live in `content/`; the `.md` URLs are served via `_redirects` rewrites to `/md/*.txt` because the static host does not serve `.md` files. Keep the bytes identical between source and served copy — `/.well-known/agent-skills/index.json` carries sha256 digests of the SKILL.md files.
- Never invent API endpoints, auth flows, or MCP servers in docs or specs. This site has no API keys, no OAuth, no MCP server, and no signed HTTP messages — do not add metadata implying otherwise.
- Never rewrite published git history.

## Key files

- `src/routes/` — TanStack file routes (`__root.tsx` owns the global head/JSON-LD)
- `src/lib/jsonld.ts` — schema.org builders
- `src/data/projects.ts` — Project type and helpers
- `public/.well-known/` — ard.json (ARD v1.0), agent-card.json, agent-skills/index.json, api-catalog
- `public/openapi.json` — documents exactly the real `/api/v1/*` static files
